# LineStudio  v0.1.0

Редактор экранов для плат ESP32 с дисплеем: экраны собираются мышкой из готовых блоков, на плату — одной кнопкой
«Залить», без кода. Программа на Python (PySide6) для Windows 10/11.

- **Превью — код самой платы.** В окне работает тот же рантайм на LVGL 9.2.2, что уходит в прошивку
  (собран в `engine/bin/line_engine.dll`), поэтому картинка совпадает с платой пиксель в пиксель.
- **Правка / Проба / Карта.** Двигать и красить блоки; пользоваться экраном мышью вместо пальца; все экраны сразу,
  связи между ними — линиями.
- **Live.** Плата на USB: правки видны на ней сразу, без заливки («⋯ → Забыть Live» — вернуть залитое).
- **Залить.** Редактор сам ставит arduino-cli и ядро ESP32 (в свою папку `tools/` или берёт уже установленное
  в Arduino15), собирает прошивку из проекта и заливает. Перед первой заливкой может сохранить прошивку платы.
- **В прошивку — только нужное:** шрифты урезаются до используемых букв (латиница + кириллица), лишних шрифтов нет.
- **Платы — паспортами.** Каждая плата — папка `boards/<id>/` с `board.json` и `port.h`
  (см. [docs/BOARDS.md](docs/BOARDS.md)). Сейчас: Guition ESP32-4848S040 (S3, 480×480) и Guition JC4880P443C (P4, 800×480).

## Запуск
Двойной щелчок по `line_studio.pyw` — недостающие библиотеки (PySide6, pyserial, fonttools) поставятся сами.
Нужен Python 3.10+ (64-битный).

## Блоки (v0.1)
Часы (формат `{HH}:{mm}` и т.п.), дата (дни и месяцы по-русски, по-украински, по-английски), стрелочные часы,
текст, плашка, кнопка (открывает экран с переходом), дуга (секунды/минуты/часы/сутки/число/яркость),
ползунок яркости. У экрана — фон и свайпы на другие экраны; свайп вправо — назад.

## Состав
| Папка | Что |
|---|---|
| `line_studio.py`, `line_studio_qt.py`, `line_studio.pyw` | программа |
| `modules/` | проект, превью, холст и карта, связь с платой, сборка |
| `app/` | тема, своя рамка окна, поле-число, обновление с GitHub |
| `runtime/` | рантайм на C (общий для платы и превью) |
| `engine/` | движок превью: исходник и готовые `line_engine.dll` / `.so` (`bash engine/build_engine.sh`) |
| `firmware/` | шаблон прошивки, драйверы, библиотеки (LVGL 9.2.2, Arduino_GFX 1.6.7), `lv_conf.h` |
| `boards/` | паспорта плат |
| `fonts/` | Montserrat (SIL OFL 1.1) |

Формат проекта — [docs/FORMAT.md](docs/FORMAT.md). Изменения — [CHANGELOG.md](CHANGELOG.md).
