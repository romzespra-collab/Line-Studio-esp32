LineStudio  v0.1.0
══════════════════

Редактор экранов для плат ESP32: собрать экраны мышкой, залить на плату одной кнопкой.

ЗАПУСК
──────
Двойной щелчок по line_studio.pyw. Библиотеки поставятся сами (нужен Python 3.10+ 64-бит).

ПЕРВАЯ ЗАЛИВКА
──────────────
1. Подключите плату кабелем USB (с данными, не только зарядка).
2. «Залить». Первый раз редактор скачает arduino-cli и ядро ESP32 3.3.7 (1,5–3 ГБ, 5–20 минут) — в папку tools\.
   Если ядро 3.3.7 уже стоит в %LOCALAPPDATA%\Arduino15 — возьмёт его.
3. Плата не отвечает — держать BOOT, нажать RST, отпустить BOOT, «Залить» ещё раз.

СТРУКТУРА
─────────
line_studio.pyw / .py / _qt.py — программа; modules\ — её части; boards\ — паспорта плат;
runtime\ и engine\ — рантайм и движок превью; firmware\ — шаблон прошивки и библиотеки;
projects\ — ваши проекты; backups\ — копии прошивок плат; config.json, secrets.json — настройки (Wi-Fi платы).

СБОРКА В EXE
────────────
build_exe.bat → line_studio.exe (класть в папку программы).
